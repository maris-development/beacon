# Guides

These guides are short. Each guide solves one problem from start to end. Each guide also links to
the reference chapters.

| Guide | What it covers |
| --- | --- |
| [Query a File Collection](/docs/2.0.0-rc4/guides/query-a-collection) | Make one table from thousands of NetCDF or Parquet files |
| [Query Data on S3](/docs/2.0.0-rc4/guides/query-s3) | Credentials, public buckets, and fast object storage |
| [Export Query Results](/docs/2.0.0-rc4/guides/export-results) | Write results to Parquet, CSV, NetCDF, GeoParquet or ODV |
| [Speed Up Slow Queries](/docs/2.0.0-rc4/guides/speed-up-queries) | Diagnose with `EXPLAIN`. Then fix with pushdown, Atlas or a materialized view |
